# alpha.2 原生 UI 验收记录

日期：2026-09-12。平台：Windows NT 10.0.26200.0。使用自包含开发构建 `artifacts/alpha2-native-check/LightHub.Desktop.exe --demo`，不操作真实 HID。数据存于独立 demo 临时目录。

## 已观察到的结果

1. 原生窗口正常打开，DPI 档位、当前读数、槽位和保存目标可见；硬件写入按钮在 demo 中保持禁用。
2. 取消档位 2 后，切换简体中文到 English，档位 2 仍停用，读数所在的档位 3/1600 DPI 保持不变，未保存标记保留。撤销后恢复原始草稿。
3. 宏页新建 `Native QA roundtrip`，添加 A 按下时出现“释放所有按键”的提示且保存禁用；补 A 释放后允许保存。
4. 保存后明确显示“Saved in library · not bound or active”，执行/绑定仍不可用。
5. Windows 原生保存对话框导出到本地 `artifacts/alpha2-native-qa/native-editor-roundtrip.lhmacro`。文件实读为 schemaVersion 1、single、A down/up 两步，没有执行输入。
6. 通过 Windows 原生打开对话框重新导入，宏库出现独立副本，原项保留。导入格式、ID 冲突和不覆写的底层规则另有自动化测试。
7. 窗口正常退出，测试进程无遗留窗口。

Windows 系统对话框的工具辅助信息曾错误标注焦点、未能使用缓存的控件索引；采用截图核对文件名焦点与内容后完成操作。此工具限制未被当作应用成功证据。

## 发现并修复

新建空宏尚未选择步骤时，键盘键和延时字段曾重叠。已改为没有选中步骤时隐藏步骤字段，headless 回归覆盖空状态和选择后的展示。
