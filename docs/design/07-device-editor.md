# 07 设备编辑界面与状态

2026-09-12，沿用设计 1.1 的设备优先流程。当前实现先在 demo/headless 和 Windows 原生窗口验证，未因此扩大设备写权限。

## 操作结构

- 设备页顶部选择编辑槽；显式启用按钮独立于保存。下方读数区标为“上次读取”，避免把用户输入或陈旧数据当作实时状态。
- 临时 DPI 使用独立输入与试用按钮，不触发闪存保存。板载档位用卡片展示，区分读数所在档位和草稿默认档位。
- 底部按钮直接写明“保存到槽 N”；未编辑时禁用。保存前仍显示差异和预检，启用前显示目标槽与 DPI。
- 只有删除当前档位时才显示替代档位选择。删除默认/Shift 档位必须重新选定或关闭 Shift，不能静默指向压缩后的另一个档位。
- 按键页使用较大的位置图；点选后在右侧编辑一个按键。保留按键选择列表、当前分配、动作搜索/分类和主键保护说明。
- 按键位置名称不随动作改变。位置/控制 ID 来自 devices.json，图示与控制映射不授予任何设备写权限。
- 宏库是独立本地入口；未实现的绑定/运行器不作为普通动作混入列表。

## 状态与副作用

选择槽、点击位置图、搜索动作、切换语言都不写设备。语言切换保存原始编辑坐标和无效输入，不能通过序列化/压缩悄悄重排用户草稿。

档位压缩时，当前档位、默认档位和 Shift 档位分别换算到已启用数组。当前档被删除时使用用户选择的原始编辑档位，再换算到设备索引；仅修改前面的档位不会改变当前速度。

只读原因和技术细节仍可查看，但不占用主操作区域的多行说明。公开状态、禁止原因和最终回读程度须与实际能力一致。

## 验收

DeviceEditorUiTests、UiTests 覆盖位置选择、动作筛选无副作用、主键保护、语言切换、稀疏 DPI 压缩、无效输入、目标槽标签及窗口尺寸。截图保留在本地 artifacts/screenshots/alpha2-device。

Windows 原生 UI 已检查 DPI 取消勾选/语言切换/撤销，以及宏编辑、校验、保存、系统文件对话框导出、导入副本和退出。这些使用 demo 数据，不能替代鼠标实际写入、输入、断电或睡眠验证。
