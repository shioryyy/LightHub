# LightHub 0.3.0-alpha.3 — 发行说明草稿

**尚未发布。** 独立审查、最终构建资源测量和制品核验未完成；最终状态以[验收清单](0.3.0-alpha.3-checklist.md)为准。

## 改进

- 板载宏只读解析（M4 第一步）：严格边界解析宏格式 1 扇区与绑定指针，未知操作码、截断、跳环、CRC 损坏一律以状态如实报告，不重写任何字节。新增 `macros <endpoint-id>` CLI 命令。
- 按键编辑页只读展示宏指针绑定指向的内容：完整宏显示解码步骤，空、不支持、截断、循环、损坏各自有明确文案；中英文随语言切换。
- 板载 profile 名称只读解析（内存模型 1 布局 A）：编辑器 profile 列表与 `inspect` 显示已存储名称；不可解码内容按无名称报告。重命名写入仍需验证驱动，保持关闭。
- 检测到未完成写入事务时，备份页顶部列出每条事务的记录备份文件、错误与设备，并提供直达恢复动作（身份校验与完整回读验证不变）；事务解决前写入保持锁定。
- 本地键盘宏可编译为板载格式 1 扇区映像（对齐、跳转保留、结束符、容量拒绝），经只读解析器往返验证。纯本地函数，不写设备。
- 脱敏诊断新增板载宏覆盖摘要（仅计数与状态）；步骤内容、profile 名称与设备身份保持排除。诊断中的应用版本改为从程序集读取。
- 新增 Issue 模板，含结构化的设备支持报告（证据门控目录流程的进料通道）。

## 支持范围

本版未新增任何设备写入能力。GPW1/Windows 经接收器连接的写入、恢复与临时 DPI 证据与 0.3.0-alpha.2 完全一致并继续生效；USB 有线模式与所有其他型号/平台保持只读。板载宏写入、绑定、profile 重命名、G-Shift 与灯光仍未开放。

## 升级和回退

- 退出旧版本后解压完整新包到新目录运行；保留旧包供回退。
- 用户数据与 `LightHub/2` 备份格式无变化；本地宏库格式无变化，旧版可读新版宏文件。恢复引导面板读取既有事务日志，未解决事务的旧版处理方式不变。
- 回退前保留用户数据副本及未完成事务引用；恢复提示未解决时不要重复写入或手动删除恢复材料。
