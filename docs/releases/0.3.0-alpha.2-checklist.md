# 0.3.0-alpha.2 发布候选验收

状态：开发中，未达到可发布结论。目标是按设计 1.1 交付有明确设备/平台边界的公开 alpha；稳定 1.0 的多家族、平台签名等门槛保留，不能因 alpha 构建成功宣称已满足。
