| 范围 | 代码入口 | 必须核对 |

| 本地宏 | `Application/MacroLibrary.cs`、`Desktop/MacroEditorViewModel.cs` | 版本拒绝、写入冲突、草稿、引用保护、回收、系统路径别名与受管路径越界；没有后台执行或设备绑定 |

| 制品 | `tools/source-identity.ps1`、`verify-package.ps1`、工作流 | 提交与 dirty 状态真实；源码归档声明不能伪装成 Git 验证；应用包不含私有数据或验收工具 |
