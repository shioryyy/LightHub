# LightHub 0.3.0-alpha.2 — 发行说明草稿

**尚未发布。** 硬件启用、物理输入、生命周期和独立审查未完成；最终状态以[验收清单](0.3.0-alpha.2-checklist.md)为准。

## 改进

- 离线宏库：手动编辑按下/释放/延时、复制、导入导出、保留未完成草稿、回收与找回。宏目前仅本地保存，不能绑定或执行。
- 设备设置：DPI 卡片、上次读取状态、明确保存目标；按键大图点选、单键编辑、动作搜索与分类。
- 修复 DPI 取消档位后的当前索引换算，以及语言切换导致稀疏/无效草稿被重排或丢失的问题。
- 修复跨平台宏存储别名与 headless 测试初始化问题；设备元数据不再散落在界面和预设映射代码中。
- 制品记录提交、dirty 状态及源码摘要；CI 验证应用包并从源码 ZIP 独立还原和测试。

## 支持范围

GPW1/Windows 的基本写入、恢复与临时 DPI 继续依赖既有精确固件/接收器证据。新启用操作仍在验收，未因代码存在而开放。G305/G304、G502 HERO、Superlight 条目用于识别/受限读取，不表示已验证写入。Linux/macOS 的构建测试不替代原生 HID 验证。

## 升级和回退

- 退出旧版本后解压完整新包到新目录运行；保留旧包供回退，勿把单个 exe 混入旧目录。
- 不自动更新、不自启、不修改设备模式或自动套用预设。已支持的板载功能不依赖后台运行。
- 沿用现有用户数据根及 LightHub/2 备份；未迁移旧日志中的绝对路径。旧版不能编辑新版宏草稿，但不应覆盖或清理不认识的文件。
- 回退前保留用户数据副本及未完成事务引用。先结束临时试用；恢复提示未解决时不要重复写入或手动删除恢复材料。
