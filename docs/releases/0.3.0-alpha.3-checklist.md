# 0.3.0-alpha.3 发布候选验收

状态：独立审查通过（A3-R1—R7 关闭），进入发布工程。目标是交付 0.3.0-alpha.2 之上的只读解析与引导改进；稳定 1.0 门槛继续保留。

## 本版定位

本版**未新增任何设备写入能力**。全部新功能为只读解析、状态展示与本地纯函数；0.3.0-alpha.2 的设备写证据原样继承，不因本版而扩大或缩小。新增能力的方法论与验收方式沿用既定制度：严格边界、状态化报告、证据门控。
