## 本版审查基调

## 重点变更

路径相对于 src，tools 相对于仓库根。候选范围 `c66b397..<最终提交>`（c66b397 为已发布的 alpha.2 tag）。

| 范围 | 代码入口 | 必须核对 |
| --- | --- | --- |
| 宏格式解析 | `Core/MacroFormat.cs` | 事件边界与载荷末检查；跳转目标必须属于宏扇区集；跳环与 4096 事件上限；未知操作码/截断/CRC 损坏状态化返回且不抛出猜测结果；`Describe` 仅展示不写 |
