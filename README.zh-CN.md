# LightHub

已确定的[产品与工程方案](docs/design/README.md)包含首版范围、技术选型、状态规则、宏与恢复设计、实施里程碑及验收清单。方案版本为 1.1；其中待实现能力不代表当前软件已经支持。

产品默认离线、板载优先。现已实现本地宏库和离线编辑器；板载宏写入与软件运行器仍未开放。固定软件配置与按应用自动切换分别规划、主动启用。使用方式见[宏编辑指南](docs/MACROS.md)，实际验证范围见[本批记录](docs/validation/macros-20260912.md)。

LightHub 新版 HID 后端已在一台 Windows GPW1 上通过非活动配置写入及恢复测试；断电和人工按键测试仍待完成。
测试写入前请阅读[验证记录](docs/validation/gpw1-windows.md)。

当前未发布迭代新增 GPW1 按键位置图与中文名称，以及带回读验证的“当前 DPI（临时）”。
临时 DPI 不修改板载配置；需要持久保存时仍使用“写入板载内存”。
其他型号的公开资料与后续计划见[设备资料调研](docs/DEVICE-RESEARCH.md)。

备份页现支持完整历史、容量统计、选中导出、批量删除和手动保留每台设备最近 10 份的清理。
未完成事务的恢复备份受保护，清理不会自动删除无法读取的备份。
宏、G-Shift 等剩余工作见[与 G HUB 的完整差距分析](docs/GHUB-GAP-ANALYSIS.md)。

面向公共开源维护的 Logitech HID++ 游戏鼠标配置工具。
新版采用 **.NET 10 LTS + Avalonia + HidSharp**，不是旧 WinForms 工具换皮。

当前版本 **0.3.0-alpha.2 开发候选**。发布状态见[候选验收清单](docs/releases/0.3.0-alpha.2-checklist.md)。已有 GPW1 非活动槽保存/恢复和临时 DPI 证据；启用槽位、物理输入及生命周期验收仍待补齐，当前不标为可发布结论。
[完整方案](docs/PLAN.md)和[技术选型](docs/ADR-001-stack.md)记录了实现范围与稳定版门槛。

## 与旧版的区别

- 支持多设备发现、接收器多个槽位、显式选择目标设备。
- 从设备读取配置数量、按键数量、内存布局、DPI 能力和回报率。
- 协议核心不依赖界面或 HID 库；可以独立测试和添加设备驱动。
- Windows、Linux、macOS 使用同一套界面，用户包可包含运行时。
- 未验证型号默认只读；可写必须匹配型号、平台及内存格式验证记录。
- 备份覆盖设备声明的全部内存扇区；普通编辑保留其他功能字节。
- 写入前备份、进程互斥、身份检查、配置冲突检测、中断日志及完整回读。
- 英文/中文界面、脱敏诊断、测试用 CLI、三平台 CI 和贡献流程。

## 当前设备支持

GPW1 是本机可以实测的设备。G305/G304、G502 HERO、G PRO X Superlight
有识别条目，但没有在这里被实测，保持只读。Linux/macOS 尚未获得实机写入证据。
跨平台构建成功不代表真实设备测试成功，增加设备 ID 也不等于完成适配。

当前编辑范围：DPI、回报率、普通按键/组合键、板载配置和恢复，以及本地单次键盘宏（按下、释放、延时）。
宏可本地保存、复制、导入导出、保留草稿、回收和找回；尚不能绑定或执行。暂不编辑 RGB、G-Shift、接收器配对或固件；不支持键盘、耳机、方向盘写入。

## 使用与构建

解压完整自包含发布目录后运行 `LightHub.Desktop.exe`；不需要安装 .NET SDK。
关闭窗口结束进程，不会安装后台服务或自动启动项。包体积和内存会大于旧 WinForms 版。

开发需要 .NET 10 SDK：

```powershell
dotnet restore --locked-mode
dotnet build --no-restore
dotnet test --no-restore
dotnet run --project src/LightHub.Desktop -- --demo
.\tools\publish.ps1 -Runtime win-x64
```

中国网络环境可以为当前终端设置 `HTTPS_PROXY=http://127.0.0.1:7890` 后还原依赖，
不需要把代理地址写入仓库。软件运行本身不访问网络。

新安装的自动备份在系统本地应用数据目录的 `LightHub/backups` 下；已有 `LightHubCommunity` 目录时继续使用它，保留事务日志中的绝对路径。更名不自动删除或合并个人数据。
新版备份格式为 `LightHub/2`；旧 WinForms 备份不会被混用。
诊断导出不包含物理序列号、原始内存和按键映射；备份文件可能包含这些信息，公开上传前需审阅。

稳定发布仍需更多型号和平台的真实设备验证、人工按键测试、安装升级测试、独立审查和签名。
现有代码、测试、发布工程和文档可以作为 GitHub 公共项目继续维护，不用再从单机脚本重做。

## 重构后的操作

- 保存与启用分开；保存备用槽不启用它，修改按键保留当前有效 DPI 档位。
- 临时 DPI 用“试用 DPI”和“结束试用”；断连或外部状态变化后不会盲目恢复旧值。
- 预设可以命名、复制保存、重命名、导入导出、载入草稿；不自动绑定应用或写设备。
- 备份支持名称、置顶和里程碑保护。删除进入回收区，可找回；永久删除单独确认。
- 型号支持进一步限定固件、连接与操作：目前 GPW1 为 BOT 74.02.0026 + C539 接收器；主动启用槽位、宏和灯光没有独立证据，保持关闭。
- 切换语言保留草稿；切设备或关闭时可以保留本地草稿，草稿恢复不会直接改设备。
